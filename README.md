# Seam for Mac

Public downloads and the signed Sparkle update feed for Seam. The application source is private.

## Download

[Download Seam 0.1.0 (1)](https://github.com/alecramos-sudo/seam-releases/releases/download/v0.1.0-1/Seam-0.1.0-1.zip)

Requires macOS 15 or later on Apple Silicon or Intel. The app is signed with Developer ID and notarized by Apple. Unzip it, then move Seam to Applications before opening it.

## Updates

Seam checks this feed through Sparkle: https://alecramos-sudo.github.io/seam-releases/appcast.xml. Choose **Seam › Check for Updates…**, or turn automatic checks on or off in Settings › Updates.
